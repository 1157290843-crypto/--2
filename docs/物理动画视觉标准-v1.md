# 物理动画视觉标准 v1

## 0. 标准身份与适用范围

- 本文是“动画制作”项目的视觉权威标准，适用于后续新建、改版和修复的全部物理动画页面。
- 本标准同时服务于教师视觉验收，以及 AI、设计和开发人员的直接实施。
- 默认必须遵守本文。题型确有特殊需要时，可以在不破坏视觉语言和可读性的前提下局部扩展；涉及颜色语义、标题结构、字号层级或响应式主布局的偏离，必须先取得教师确认。
- 本标准记录页面外壳与品牌、颜色语义、六级字号、三栏及响应式布局、引导演示与实验指南入口、舞台控制条、通用浮动引导卡、紫色重点观察光晕、公式排版，以及可复用 CSS Token 和正误示例。
- 人工逐页验收清单不属于本文 v1 的正式范围。

## 1. 颜色标准

### 1.1 基础界面色

| Token | 色值 | 用途 |
|---|---:|---|
| `--surface-page` | `#F7F4ED` | 页面和左右侧栏的暖白底色 |
| `--surface-panel` | `#F7F4ED` | 参数、观察面板背景 |
| `--surface-raised` | `#FFFDF8` | 卡片、浮层、次级按钮背景 |
| `--border` | `#D8D6CF` | 卡片边框、栏分隔线、输入控件边线 |
| `--text-strong` | `#14213D` | 标题、正文主文字、关键标签 |
| `--text-muted` | `#5C6678` | 辅助说明、次级标签、弱化信息 |
| `--action` | `#2557D6` | 主按钮、当前选项、焦点操作 |
| `--on-action` | `#FFFFFF` | 主操作色上的文字和图标 |

使用规则：

- 页面和侧栏保持暖白，避免改成大面积冷灰或纯黑。
- 卡片使用轻微层级差，不用重阴影制造层级。
- 主操作蓝只用于“当前可执行动作”和“选中状态”，不能成为大面积装饰色。
- 主文字与次文字必须保持明确层级，不能用浅灰承载重要结论。

### 1.2 状态色

| Token | 色值 | 用途 |
|---|---:|---|
| `--safe` | `#277A51` | 正确、完成、安全、满足条件 |
| `--safe-soft` | `#E5F4EB` | 成功状态浅底 |
| `--danger` | `#B9384D` | 错误、超限、危险、失败 |
| `--danger-soft` | `#FAE9EC` | 危险状态浅底 |
| `--warning` | `#8D5517` | 提醒、注意、尚未完成 |
| `--warning-soft` | `#FFF4E7` | 提醒状态浅底 |
| `--rising` | `#A84D19` | 增大、上升、趋强 |
| `--rising-soft` | `#FFF0E7` | 上升趋势浅底 |
| `--falling` | `#24569D` | 减小、下降、趋弱 |
| `--falling-soft` | `#EDF4FF` | 下降趋势浅底 |

使用规则：

- 状态色表达状态，不承担无意义装饰。
- 危险红不能用作普通主按钮。
- 上升和下降必须同时有文字、箭头或数值变化，不能只靠颜色传达。
- 浅底与对应深色文字成对使用。

### 1.3 方向与物理可视化色

| Token | 色值 | 默认语义 |
|---|---:|---|
| `--prograde` | `#E66D26` | 顺行、正向或热方向 |
| `--retrograde` | `#2557D6` | 逆行、反向或冷方向 |
| `--viz-circular` | `#38BDF8` | 圆轨道、主曲线、冷色对象 |
| `--viz-transfer` | `#FB923C` | 转移轨道、对比曲线、热色对象 |
| `--viz-reference` | `#55617C` | 参考轨迹、辅助线、非主对象 |
| `--viz-velocity` | `#4ADE80` | 速度或运动状态 |
| `--viz-gravity` | `#F6C453` | 重力、场力或关键受力 |
| `--viz-required` | `#C084FC` | 必需量、目标量、补充关系 |
| `--viz-apsis` | `#F8FAFC` | 关键位置、拱点、强调标记 |
| `--viz-escape` | `#FB7185` | 逃逸、超限、失稳路径 |

使用规则：

- 同一页面内，同一物理量必须始终使用同一种颜色。
- 不同物理量不要因为“好看”而临时交换颜色。
- 颜色必须与图例、标签或直接标注同时出现。
- Canvas、SVG、DOM 图例统一从 CSS Token 读取语义色，不在绘图代码里重复写散乱的十六进制颜色。
- 光谱、真实材料色、渐变介质和结构阴影可以使用题型专属颜色，但不能覆盖以上语义角色。

### 1.4 深色实验舞台

| Token | 色值 | 用途 |
|---|---:|---|
| `--stage` | `#0B1424` | 实验舞台和主要图表背景 |
| `--stage-line` | `#263650` | 舞台边线、工具栏边线、暗底网格 |
| `--stage-text` | `#F4F8FF` | 舞台主要文字 |
| `--stage-muted` | `#91A3BF` | 舞台辅助文字、次级刻度 |

舞台可以叠加轻微深蓝径向渐变，但基础底色必须保持 `--stage`。不使用纯黑背景。

### 1.5 教学关注色

| Token | 色值 | 用途 |
|---|---:|---|
| `--focus` | `#9A83FF` | 引导演示中的当前唯一重点边框和光晕 |

- 关注紫只用于当前步骤的教学焦点，不作为普通按钮、成功、警告或装饰色。
- 中心边框最浓，向外的多层光晕逐层降低不透明度，形成由浓到淡的层次。
- `--focus` 不替换 `--viz-required`：前者表示当前教学焦点，后者仍表示必需量、目标量或补充关系。

## 2. 标题与品牌结构

### 2.1 固定结构

所有页面顶部使用统一结构：

```text
┌─────────────────────────────────────────────┐
│ 返回位   罗   老罗物理 · 探究实验            │
│              当前动画标题                    │
└─────────────────────────────────────────────┘
```

标准 HTML：

```html
<header class="topbar template-header">
  <div id="headerBackSlot"></div>
  <div class="brand">
    <div class="brand-mark" aria-hidden="true">罗</div>
    <div class="brand-copy">
      <p class="eyebrow">老罗物理 · 探究实验</p>
      <h1>当前动画标题</h1>
    </div>
  </div>
</header>
```

### 2.2 品牌规则

- 品牌字固定为“罗”，深蓝底、白字、粗体。
- 眉题固定为“老罗物理 · 探究实验”，不得替换为实验编号或版本信息。
- `#headerBackSlot` 始终保留，供网站嵌入返回按钮；独立页面中允许为空。
- 页面只设置一个可见 `h1`。
- 标题写教学主题，不写文件编号、版本号、开发状态或“高级重构版”等技术信息。
- 标题推荐格式为“主题｜学习任务”，例如“卫星变轨｜从圆轨道到新圆轨道”。
- 标题保持单行；空间不足时省略号截断，不把整个标题栏撑高。

### 2.3 标题栏尺寸

| 场景 | 标题栏高度 | “罗”标记 | 主标题 |
|---|---:|---:|---:|
| 宽屏 | `62px` | `38×38px` | `20px` |
| 窄屏 `≤960px` | `56px` | `34×34px` | `16px` |
| 短横屏 `≤960×540` | `46px` | `30×30px` | `14px` |

- 眉题始终为 `11px`，包括短横屏，不允许通过 `display:none` 隐藏。
- 主标题字重建议 `800`，行高 `1.15`。
- “罗”字重建议 `900`。
- 标题栏必须横跨页面顶部，不能在短横屏中被隐藏。

### 2.4 引导演示与实验指南入口

- 入口区位于统一标题栏下方、主舞台上方，不进入标题栏、左右侧栏或浮动引导卡。
- 一个动画可以有一个或多个引导演示情境入口，数量由唯一主教学目标决定；实验指南与情境入口同层。
- 入口按钮统一高度、圆角、边框、间距和选中语义，主要触控目标不小于 `44×44 CSS px`。
- 当前情境使用主操作蓝选中态；实验指南打开状态同时通过可见样式和 `aria-expanded` 表达。
- 窄屏与短横屏仍保留这一区域的入口职责，不得把入口塞入参数/观察标签或用隐藏入口换取舞台空间。

标题栏后的正式结构统一为三栏实验布局；入口只属于主舞台列：

```html
<main class="experiment-layout">
  <aside class="control-panel"><!-- 左侧参数区 --></aside>
  <section class="stage-column">
    <nav class="guide-entry-bar" aria-label="引导演示与实验指南">
      <button class="guide-entry is-active" type="button" aria-pressed="true">
        情境一
      </button>
      <button class="guide-entry" type="button"
              aria-expanded="false" aria-controls="experimentGuide">
        实验指南
      </button>
    </nav>
    <section class="stage">
      <!-- Canvas / SVG；播放、倍速和重置仍在舞台内部底部 -->
    </section>
  </section>
  <aside class="observe-panel"><!-- 右侧观察区 --></aside>
</main>
```

- `.guide-entry-bar` 可以容纳一个或多个情境按钮及实验指南按钮；按钮数量增加时保持单行横向滚动，不缩小主要触控目标。
- `.stage-column` 只管理中间列的“入口行 + 剩余舞台”两行；左右侧栏从标题栏下开始，不因入口整体下移。
- `.experiment-layout` 统一扣除标题栏高度，入口位于其内部，不得再在布局外叠加一行造成总高度超出视口。

## 3. 六级字号

### 3.1 字体族

```css
--font-ui: ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
  "PingFang SC", "Microsoft YaHei", sans-serif;
```

正文、按钮、输入框、选择器、Canvas 和 SVG 标注统一使用该字体栈。公式可以使用原生 MathML 或适当的数学字体。

### 3.2 字号层级

| 层级 | Token | 大小 | 主要用途 |
|---|---|---:|---|
| T1 | `--type-20` | `20px` | 宽屏页面主标题 |
| T2 | `--type-16` | `16px` | 窄屏主标题、极少数核心大读数 |
| T3 | `--type-14` | `14px` | 短横屏主标题、重要提示、核心读数、警报 |
| T4 | `--type-13` | `13px` | 正文、主要按钮、主要控制项 |
| T5 | `--type-12` | `12px` | 卡片标题、参数标签、数据、公式、表格 |
| T6 | `--type-11` | `11px` | 眉题、提示、图例、工具栏、辅助状态 |

### 3.3 字号规则

- 可见的 DOM、Canvas 和 SVG 文字不得低于 `11px`；原生 MathML 内部排版层级除外。
- 禁止使用 `8px`、`9px`、`10px`、`10.5px`、`13.5px`、`15px`、`18px`、`21px` 等临时字号。
- 禁止使用 `font-size:0` 隐藏文字后再用伪元素替换。
- 禁止使用整体 `transform:scale()` 缩小界面文字。
- 空间不足时优先缩短次要文案、减少刻度数量、折叠次级内容或允许局部滚动。
- 正文推荐行高 `1.5`；紧凑标签推荐 `1.35`；标题行高 `1.15`。

## 4. 三栏布局

### 4.1 信息职责

```text
┌────────────────────── 顶部统一标题栏 ──────────────────────┐
├──── 左侧参数区 ────┬── 引导演示 / 实验指南入口 ──┬──── 右侧观察区 ────┤
│ 条件、参数、预设    ├──────── 中间主舞台 ────────┤ 数据、结论、图表    │
│                    │ Canvas / SVG / 核心现象    │                    │
│ 约 220–280px       │ 弹性占满，视觉权重最大      │ 约 240–314px       │
└────────────────────┴───────────────────────────┴───────────────────┘
```

左侧参数区：

- 实验条件、可调参数、模式、预设。
- 参数按教学顺序排列，每一步只突出一个主要操作焦点。
- 内容过多时只在左栏内部纵向滚动。

中间主舞台：

- 承载 Canvas、SVG、核心动画、关键物理量和舞台工具栏。
- 必须是三栏中最大区域，通常占可用内容宽度的 `50%–60%`。
- 同时高亮的核心物理信息默认不超过两组。
- 舞台控件属于舞台，不应散落进左右面板。

右侧观察区：

- 实时数据、图表、状态、结论、公式和观察提示。
- 不重复左侧参数，不放置无关的第二套控制系统。
- 内容过多时只在右栏内部纵向滚动。

### 4.2 栏宽标准

推荐 Grid：

```css
grid-template-columns:
  clamp(220px, 22vw, 280px)
  minmax(0, 1fr)
  clamp(240px, 21vw, 314px);
```

允许范围：

- 左栏：`220–280px`，推荐基准约 `260px`。
- 中栏：`minmax(0, 1fr)`，弹性占满剩余空间。
- 右栏：`240–314px`，推荐基准约 `280px`。
- 页面内边距：`8–12px`。
- 栏间距：`8–12px`。

布局规则：

- 中栏必须设置 `min-width:0`，Canvas/SVG 外层也必须允许收缩。
- 左右栏使用独立纵向滚动，页面本身不得出现横向滚动。
- Canvas 使用 `display:block;width:100%;height:100%`，并由脚本同步 backing store。
- 不得用固定超宽 Canvas、长公式或 `min-content` 把中栏撑出页面。
- 1024px 宽度仍优先保持三栏；必要时收紧两侧栏和间距，不缩小文字。

### 4.3 主舞台底部控制条

- 需要物理时间控制的动画，把播放、暂停、`0.25×`、`0.5×`、`1×`、`2×`、必要观察范围和重置统一放在主舞台内部最下方，作为物理时间/速度控制。
- 控制条不得进入左侧参数栏、右侧观察栏、标题栏或浮动引导卡。
- 播放倍速的选中态必须清楚；控制条不得遮挡本步主要观察对象，引导卡默认位于其上方。
- 不需要物理时间控制的动画不为形式统一而增加空控制条。

## 5. 窄屏与短横屏布局

### 5.1 窄屏 `≤960px`

结构顺序：

```text
标题栏
引导演示 / 实验指南入口
主实验舞台
参数设置 / 观察数据 两个标签
当前活动面板
```

规则：

- 不再同时展示左右两个侧栏，只展示一个活动面板。
- 两个标签固定为“参数设置”和“观察数据”。
- 切换面板不得重置动画、参数、时间、图表或观察状态。
- 活动面板独立纵向滚动。
- 舞台优先显示，不能被面板推到页面底部。
- 标签使用原生按钮并提供可访问的 tab/tabpanel 关系。
- 入口栏随舞台列进入单列后全宽保留；`.stage-column` 把剩余高度交给舞台，不得挤压或裁切主舞台、底部控制条和活动面板，也不得缩小核心字号。

### 5.2 短横屏 `≤960px` 且高度 `≤540px`

```text
┌────────────────────── 标题栏 ──────────────────────┐
├── 引导演示 / 实验指南入口 ────────┬── 参数/观察标签 ──┤
├──────────── 左侧主舞台 ───────────┼──────────────────┤
│       约占内容宽度 60%–66%        │  单个活动面板     │
│                                  │  独立纵向滚动     │
└──────────────────────────────────┴──────────────────┘
```

规则：

- 标题栏保持显示，主标题为 `14px`，眉题仍为 `11px`。
- 左侧舞台约占 `60%–66%`，右侧区域约占 `34%–40%`。
- 推荐列定义：`minmax(0, 1.55fr) minmax(250px, .8fr)`。
- 右侧顶部放两个横向标签，下方放一个活动面板。
- 禁止竖排标签、隐藏标题、整体缩放页面或把字号降到 `11px` 以下。
- 舞台工具栏必须保持完整可操作；次要说明可以折叠或缩短。
- 入口栏保留在左侧主舞台列顶部，右侧参数/观察标签和活动面板从标题栏下开始；`.stage-column` 把剩余高度交给舞台，不得挤压或裁切主舞台、底部控制条和活动面板，也不得缩小核心字号。

### 5.3 面板状态要求

- 宽屏：左右面板同时可见，不显示移动端标签。
- 窄屏与短横屏：标签可见，仅一个侧栏可见且可访问。
- 返回宽屏时，左右面板重新同时显示，但保留当前实验状态。
- 标签至少支持点击、Enter、Space；推荐支持左右方向键、Home 和 End。

## 8. 通用浮动引导卡

本节适用于所有包含引导演示、分步引导或可恢复学习步骤的动画。引导卡属于主舞台的教学覆盖层，不属于标题栏、左侧参数区或右侧观察区。

### 8.1 默认结构与位置

- 引导卡默认浮动在主舞台内部下方中央、舞台控制条上方，采用暖白卡片和关注紫描边。
- 引导卡不得改成占据标题栏的状态条，也不得作为固定网格行把主舞台整体向下挤压。
- 标题栏继续严格保留最左侧 `#headerBackSlot`，其后才是“罗”品牌标记和标题；引导状态不得占用返回预留位。
- 宽屏默认宽度推荐为 `min(72%, 720px)`；短横屏使用紧凑文案和可夹取宽度，不得通过缩小到 `11px` 以下解决空间问题。
- 默认位置应避开本步主要观察对象和舞台控制条。若仍发生遮挡，学生可以拖动卡片。

### 8.2 拖动规则

- 引导卡必须提供明确的六点拖动手柄；仅手柄与标题空白区构成拖动面，正文、“为什么？”、关闭和操作按钮不得触发卡片移动。
- 触控拖动使用 Pointer Events 和 `setPointerCapture()`；拖动面设置 `touch-action:none`，最小触控区域为 `44×44 CSS px`。
- 第一次有效拖动后，引导卡转为浮动定位；学生可以在页面内容安全区内自由移动，但不得拖出屏幕。
- 引导卡与安全区边缘至少保持 `12px`。标题栏、系统安全区和不可覆盖的固定工具栏不属于可停放区域。
- 教学步骤变化、播放或暂停、展开或收起“为什么？”以及参数/观察标签切换，都必须保留并重新夹取当前卡片位置。
- 页面尺寸、分屏、方向或卡片高度变化时必须重新夹取位置，不能使拖动手柄或关闭按钮移出可视区域。
- “继续引导”保留本次学习会话中的卡片位置；“恢复默认布局”或开始一个全新的引导演示任务时，卡片才回到舞台下方中央。

### 8.3 状态与层级

- 拖动只改变引导卡的界面位置，不得修改物理时间、参数、预测、教学步骤、图表或实验结果。
- 层级从下到上依次为场景内容、紫色重点光晕、引导卡和实验指南等模态层；光晕必须 `pointer-events: none`，不能阻断舞台操作。
- 卡片关闭后保留当前物理状态，并在自由探索中提供“继续引导”入口。
- 当前步骤发生错误或条件未满足时，引导卡停留在本步并给出可恢复说明，不得因拖动或关闭而把步骤误标为完成。

### 8.4 可访问性与降级

- 拖动手柄提供清楚的可访问名称，例如“拖动引导卡”；拖动只是布局增强，不得成为完成教学任务的必要操作。
- 键盘、辅助技术或无法精确拖动的学生，使用默认位置仍能完成全部步骤、展开说明、关闭和继续引导。
- `prefers-reduced-motion: reduce` 下取消重点光晕的呼吸扩散，但保留静态边框和教学焦点；页面不设置专门的减动态按钮。
- 引导卡中的标题、正文、按钮和公式继续遵守六级字号、正确上下角标和至少 `44px` 的主要触控目标要求。

### 8.5 正误示例

正确：

- 卡片默认位于舞台下方中央，通过六点手柄拖到不遮挡观察对象的位置。
- 拖动后切换步骤或展开“为什么？”，卡片仍保持在安全范围内。
- 在短横屏中卡片自动夹取，标题栏、返回位和舞台控制条始终可用。

错误：

- 整张卡片任意位置都能拖动，导致点击“下一步”时卡片跟随移动。
- 卡片可以被拖出屏幕，或拖到标题栏上遮挡返回按钮和品牌标题。
- 拖动卡片会暂停、重置动画或改变教学步骤。
- 用固定引导条挤压主舞台，或在短横屏中把正文缩到 `10px`。

### 8.6 紫色重点观察光晕

- 每一步原则上只显示一个联合重点区域；相关对象合并为一个区域，不给多个零散对象分别套框。
- 使用 `--focus`：中心边框最浓，向外形成多层由浓到淡的紫色光晕。循环层从目标边缘由内向外柔和扩散，不使用生硬开关式闪烁。
- 光晕保持到本步完成或切换步骤，并始终设置 `pointer-events: none`，不得阻断学生操作。
- 不增加“重点观察”悬浮标签；引导卡中的“重点看”承担文字说明。
- 除必要的物理运动外，紫色重点光晕是项目唯一通用的循环提示动效。
- 页面不设置专门的减动态按钮；在 `prefers-reduced-motion: reduce` 下取消循环呼吸扩散，保留静态紫色边框和渐淡光晕。
- 光晕是与目标同步定位的舞台覆盖层：主舞台建立相对定位和明确 stacking context；光晕相对舞台绝对定位，位于场景内容之上且引导卡和模态层之下。

## 9. 公式、物理量与上下角标

### 9.1 适用范围与字号

- 本节适用于 DOM、原生 MathML、Canvas 和 SVG 中所有向学生显示的公式、物理量、角标、分式、单位和矢量符号。
- 简单行内公式的根字号不得低于 T5 `12px`；含标准分式、根式或多层脚本的核心或展示公式根字号不得低于 T2 `16px`。
- HTML、Canvas 和 SVG 手工排版的角标、分子、分母及其他可见字形不得低于 `11 CSS px`。
- 原生 MathML 内部由浏览器数学排版器产生的层级缩放不套用上一条的逐节点字号下限，但 `<math>` 根字号仍须满足本节要求，并须在代表尺寸下人工确认可读。
- 禁止以全局角标等大字号覆盖、整体 `transform: scale()` 或公式栅格化规避字号和排版要求。

### 9.2 分式与普通斜杠

- 凡斜杠承担数学除法语义，均使用上下分子、分母和水平分数线的标准分式；MathML 使用 `<mfrac>`。
- 普通斜杠只允许作为约定单位字符串的一部分，例如 `m/s`、`m/s²`、`kg/m³`、`N/C` 和 `V/m`；这类单位保持正体，不改成上下分式。
- 同一单位字符串出现多个除法层级时，使用括号或负指数消除歧义，不写无括号的重复斜杠。
- Canvas 和 SVG 中的标准分式必须分别布局分子、分母和水平分数线，不能绘制普通斜杠字符串代替。

### 9.3 变量、单位和数值

- 单字符物理变量使用数学斜体；数字、单位符号、描述性缩写和函数名使用正体。
- HTML 简单物理量使用 `<var>`；MathML 中变量、数字、运算符分别使用 `<mi>`、`<mn>`、`<mo>`，单位使用正体节点，不把多个语义 token 合并进一个 `<mi>`。
- 数值与单位之间保留一个不换行间距，数值和单位不得在行尾拆开；单位字符串内部不在斜杠两侧加空格。
- 不向学生显示带下划线或函数包装的程序式物理量文本。

### 9.4 上下角标与作用域

- 每个上标或下标必须绑定明确底数；底数可以是单个变量，也可以是整个物理量或带括号表达式。
- MathML 的单下标、单上标和配对上下标分别使用 `<msub>`、`<msup>`、`<msubsup>`；指数作用于复合量时，先用 `<mrow>` 构成完整底数，再套 `<msup>`。
- 简单 HTML 只允许 `<var>` 配合单个 `<sub>` 或 `<sup>`；同一底数同时有上下标、存在复合底数或可能产生作用域歧义时，必须改用 MathML。
- HTML 角标仅使用公式作用域规则，例如 `max(var(--type-11), .75em)`，不设置全局 `sub/sup` 字号。
- Canvas 和 SVG 必须把底数与脚本作为独立文本 run，显式计算宽度、脚本偏移和基线；脚本不得靠下划线文本或 Unicode 外观冒充。

公式作用域内可使用：

```css
.formula sub,
.formula sup {
  font-size: max(var(--type-11), .75em);
  line-height: 0;
}
```

### 9.5 矢量

- 每个动画选择并坚持一种公式矢量记法，默认使用变量上方箭头；同一物理量不得混用上箭头、粗体和程序式函数包装。
- MathML 的上方矢量箭头使用 `<mover accent="true">`；带角标的矢量先构成矢量节点，再用 `<msub>`、`<msup>` 或 `<msubsup>` 绑定脚本。
- Canvas 和 SVG 的矢量箭头、公式、图例和可访问名称必须对应同一物理量；矢量方向不得只靠颜色传达。

### 9.6 Canvas、SVG 与可访问性

- Canvas 公式使用 `measureText()` 按 CSS 像素计算文本 run、角标、分子、分母和分数线；DPR 只调整 backing store，不改变 CSS 字号阈值。
- SVG 使用独立 `<text>/<tspan>` 或等价节点表达底数、脚本、分子与分母，使用 `<line>` 表示分数线，并显式设置位置和基线。
- 每个非纯装饰公式必须具有完整可访问名称或同步的 DOM 等价文本，阅读顺序表达变量、角标、运算关系和单位。
- SVG 至少使用 `<title>` 配合 `aria-labelledby`；Canvas 使用邻近或 fallback DOM 等价文本。可见公式和可访问文本必须由同一物理状态更新。
- 只有在已有等价语义文本时，视觉重复副本才可以从辅助技术树中隐藏。

```css
}
```

Canvas 使用邻近 DOM 等价文本；绘制逻辑和文本从同一物理状态生成：

```html
<canvas id="formulaCanvas" aria-describedby="formulaText"></canvas>
<span id="formulaText" class="visually-hidden">
  加速度等于速度变化量除以时间变化量
</span>
<script>
  const numeratorWidth = ctx.measureText(numerator).width;
  const denominatorWidth = ctx.measureText(denominator).width;
  // 以 CSS px 分别布局分子、分母和水平分数线；DPR 只缩放 backing store。
</script>
```

### 9.8 错误示例

- 把数学除法写成 `a=Δv/Δt`，或在 Canvas/SVG 中把除法绘制成普通斜杠字符串。
- 向学生显示 `v_0=5m/s`、`r_0` 或函数包装式物理量文本。
- 把变化符号与变量合并进一个 `<mi>` 节点，或把配对上下标拆成互相猜测作用域的 HTML 节点。
- 用全局等大角标规则覆盖全部 `sub`/`sup`，或把公式整体缩放、栅格化来规避排版要求。
- Canvas/SVG 公式缺少完整可访问名称或同步的 DOM 等价文本。
