## 2. 背景与问题诊断

现有页面已同时包含器材结构、打点原理、规范操作、机型比较、纸带计算和错误诊断。三维器材模型、视觉语言和纸带点迹内核具有复用价值，但同一页面中的多个独立教学目标造成信息堆叠、观察重点不唯一和平板侧栏过长。

本设计将原项目拆为三个学习时长约 3–8 分钟的独立动画，使每个文件只有一个主教学目标，并保留一个直接服务主目标的辅助目标。

## 3. 已确认的产品结构

### 3.1 输出文件

1. `02A-打点计时器结构与原理-v1.html`
2. `02B-打点计时器规范操作-v1.html`
3. `02C-纸带数据处理-v1.html`

三个文件均为可独立运行的自包含 HTML：

- CSS 和 JavaScript 内嵌；
- 不依赖另外两个文件的运行状态；
- 不加载音频、在线接口或外部图片；
- 可通过只监听 `127.0.0.1` 的本地静态服务器单独验证。

### 3.2 文件间的关系

三个文件共用同一套视觉规范、器材几何数据和经校验的打点时序逻辑，但在交付形态中各自内嵌所需代码。学生可单独进入任一文件，无须按 A→B→C 强制学习。

## 6. 02A：结构与工作原理

### 6.1 目标和范围

- 主目标：学生能够根据内部结构解释两种计时器如何形成等时间间隔点迹。
- 辅助目标：理解 `T = 1/f`，并知道 50 Hz 时 `T = 0.02 s`。
- 不进入试验操作训练、纸带定量计算或完整电路推导。

### 6.2 表现和视角

- 高质量三维主场景，结论阶段使用轻量二维原理链；
- 默认为前上方三分之四视角；
- 快捷视角为标准、电磁剖面、电火花剖面和沿纸带方向；
- 外壳渐隐或局部剖切替代零件全屏爆炸展开。

### 6.3 教学脚本

1. 从外观寻找纸带通道、打点位置和电源连接位置。
2. 聚焦电磁式内部结构。
3. 慢放一次“电磁状态变化—振动部件运动—振针打点”。
4. 切换电火花式，观察脉冲放电和点迹形成。
5. 对比两种打点方式，得出共同的时间基准结论。

### 6.4 核心功能

1. 正式三维剖面；
2. 部件点击与原理链逐步高亮；
3. 一次打点过程的通电、暂停和慢放。

可选功能仅保留一张轻量双机型结论卡。若必须继续缩减，先删除完整对照表，不删除三维内部结构。

### 6.5 物理校验要求

- 以教材常见型号和可获得实物资料校核部件名称、相对位置和作用链；
- 不把某一型号的内部结构表述为所有型号的唯一结构；
- 振针振幅、火花尺寸和发光强度可为可视化而适度夸张，但必须标明为视觉辅助；
- 不将电火花式表述为“无接触、完全无阻力”，使用“对纸带的附加阻力较小”。

## 7. 02B：规范实验操作

### 7.1 目标和范围

- 主目标：学生能按正确顺序完成打点计时器实验，并解释关键操作顺序的原因。
- 辅助目标：根据纸带结果识别“先放车后通电”和“停车后未及时断电”。
- 不讲解完整内部原理，不进行速度或加速度定量计算。

### 7.2 表现和视角

- 三维直接操作与二维纸带后果反馈；
- 默认为可同时看见计时器、纸带和小车的侧前方视角；
- 每个步骤开始时自动切换最佳教学视角；
- 穿带步骤使用局部放大或局部透视，不重复 A 的完整剖面学习。

### 7.3 状态机和完成条件

1. **固定计时器**：固定夹到位、计时器方向正确后完成。
2. **穿纸带**：纸带通过正确通道，并完成当前机型的接触关系检查。
3. **接通电源**：已完成穿带检查，且视觉脉冲和点迹达到稳定状态。
4. **释放小车**：只有已通电时才判定为正确，点迹间隔随运动变化。
5. **断电取带**：小车停止后先断电，再取出纸带。

步骤按钮不得跳过完成条件直接把错误状态标记为完成。自动演示和分步引导共用这一状态机。

### 7.4 直接操作

- 点击或拖动固定夹；
- 拖动纸带穿过限位通道；
- 点击电源开关；
- 解锁或释放小车；
- 断电；
- 拖出纸带。

所有可操作对象有触控热区、可操作高亮、手势提示和错误后的可恢复路径。

### 7.5 错误反馈

核心后果对比只保留：

- 先放车后通电：纸带起始段缺失点迹；
- 停车后未及时断电：纸带末端形成重复深点。

没穿限位通道、当前机型的耗材安装错误和计时器未固定作为对应步骤的即时校验，不扩展为额外教学章节。

### 7.6 核心功能

1. 场景内完成五步直接操作；
2. 每步完成条件与错误可恢复状态；
3. 关键顺序错误与纸带后果对比。

机型切换为可选功能。若范围必须继续缩减，先删除 B 中的机型切换，默认以电磁式完成规范操作教学。

## 8. 02C：纸带数据处理

### 8.1 目标和范围

- 主目标：学生能利用纸带上的等时间点迹计算某点速度和匀变速运动加速度。
- 辅助目标：理解纸带附加阻力可使实际加速度小于理想条件下的加速度。
- 不进入三张函数图像、逐差法、多组平均、随机误差和不确定度分析。

### 8.2 表现和视角

- 二维固定物理比例纸带为主场景；
- 上方可使用轻量 2.5D 小车与时间游标联动；
- 纸带不因点迹跨度不同而自动拉伸到相同宽度；
- 不展开完整计时器内部结构。

### 8.3 物理内核

打点时刻：

`t_n = n / f`

计数点时间间隔：

`T' = k / f`

其中 `k` 为相邻计数点包含的打点间隔数。

理想化纸带阻力模型：

`a_actual = a_ideal - f_tape / m`

点迹位置：

`x_n = v_0 t_n + 0.5 a_actual t_n^2`

中间计数点 B 的速度：

`v_B = (x_C - x_A) / (2T') = (s_1 + s_2) / (2T')`

对连续相等时间内的两段位移：

`a = (s_2 - s_1) / T'^2`

模型必须在界面和状态中区分：

- `a_ideal`：不计纸带附加阻力时的理想加速度；
- `a_actual`：小车和纸带实际按照的加速度；
- `a_tape`：由点迹和位移计算得到的加速度。

在无随机误差时，`a_tape` 应与 `a_actual` 在数值容差内一致，而不是与 `a_ideal` 强制一致。

电磁式和电火花式使用 `f_tape_em > f_tape_spark >= 0` 的理想化关系。未经实物数据校准前，界面不宣称具体阻力数值代表所有实际仪器。

### 8.4 学生可调与系统计算量

学生可调：

- 理想加速度；
- 计时器机型；
- 计数点间隔，默认为每 5 个打点间隔取一点。

系统固定：

- `v_0 = 0`；
- `f = 50 Hz`；
- 小车质量和两类纸带附加阻力参数。

系统计算：

- 实际加速度；
- 点迹位置；
- 计数点对应时刻；
- 两段位移；
- 速度和加速度参考值。

### 8.5 教学脚本

1. 确认 50 Hz 时相邻点的时间间隔。
2. 每 5 个间隔选择计数点，得到 `T' = 0.10 s`。
3. 拖动选择 A、B、C 三个连续计数点。
4. 测量 `s_1` 和 `s_2`。
5. 先预测 B 点速度范围，再展开计算。
6. 利用位移差计算加速度。
7. 拖动时间游标，验证 B 点与小车时刻的对应。
8. 可选切换机型，观察纸带阻力的定性影响。

### 8.6 核心功能

1. 可拖动选择计数点；
2. 位移测量与速度、加速度公式联动；
3. 纸带时刻、时间游标与小车状态联动。

机型阻力比较是直接服务辅助目标的可选功能。若必须继续缩减，先删除该比较，不删除计数点、位移和时刻的对应操作。

## 10. 状态与模块边界

每个 HTML 内部至少区分以下责任，即使交付时仍为单文件：

1. **物理状态**：时间、机型、点迹、小车运动和开关状态。
2. **教学状态**：当前步骤、完成条件、预测、提示和已解锁结论。
3. **场景模块**：几何数据、摄像机、渲染、部件拾取和视角预设。
4. **交互模块**：触控热区、拖动、按钮、键盘可达性和错误恢复。
5. **展示模块**：主场景、观察卡、纸带、公式和底部控制。
6. **教学脚本**：自动演示和分步引导共用的单一步骤定义。

所有展示从同一份物理状态和教学状态派生，不使用相互独立的计时器推动主场景和纸带。

## 11. 异常和边界处理

- 修改必须重新运行的条件时，清空旧点迹并明确提示“新条件将重新运行”；
- 学生尝试未解锁操作时，显示原因和恢复指引，不只禁用按钮；
- 三维部件或标签接近画布边缘时，标签在可视区域内自动避让；
- 有效加速度必须大于零，不合法参数不进入模拟；
- 点迹过密时不改变物理比例欺骗观察，而是提供放大、滚动或局部视窗；
- 视口变化后重新计算画布和触控坐标，不丢失当前教学状态；
- 重置恢复默认参数、标准视角、第一教学步骤和未解锁结论。

## 12. 可达性和可读性

- Canvas 有明确的 `aria-label`；
- 机型、剪切、播放和学习模式控件使用真实按钮状态；
- 不只依赖颜色区分机型、正误或重点，同时使用文字、图形、线型和标签；
- 关键状态变化通过简短文字状态区通知；
- 公式附带可读文字语义和单位；
- 主流键盘操作可访问播放、步骤、机型和视角恢复，不要求键盘用户在 Canvas 上执行精密拖动。

## 13. 性能要求

- 画布像素比设置合理上限，不按超高分屏幕物理像素无限扩大；
- 缓存可复用几何和材质数据；
- 不可见模块停止渲染和高频 DOM 更新；
- 非重点实时数据使用低于主动画的刷新频率；
- C 不加载完整三维内部结构渲染流程；
- 性能不足时先减少装饰光效、非必要标签和隐藏模块刷新，不降低 A 的内部结构质量或 B 的直接操作反馈。

## 14. 验证和验收标准

### 14.1 通用验证

- 三个 HTML 分别在临时 `127.0.0.1` 静态服务器上打开；
- 浏览器控制台无未处理错误；
- 各自的自动演示、分步引导和自由探索共用物理状态，不产生显示不同步；
- 验证 0.25×、0.5×、1×、2× 下关键时刻和结果一致；
- 验证 1180×820、1024×768、960×540 下无面板叠压、工具条裁切或主操作不可见；
- 验证标题区位置、品牌和基本结构未改变；
- 验证无音频标签、资源请求、控件或预留接口。

### 14.2 A 的验收

- 学生能通过三维剖面找到关键打点链中的部件；
- 一次打点慢放中，高亮部件、运动和点迹时序一致；
- 50 Hz 时打点时刻间隔在数值容差内为 0.02 s；
- 两种机型的文案、电源和打点方式无混淆。

### 14.3 B 的验收

- 正确操作可完成五步流程；
- 未完成前置条件时不会被判定为正确完成；
- 先放车后通电会生成缺失起始点迹的纸带；
- 停车后未断电会在末端形成重复深点；
- 学生可从错误状态恢复，不必刷新页面。

### 14.4 C 的验收

- 固定参数下点迹位置与运动方程一致；
- 学生选择不同计数点间隔时，`T'` 及单位正确更新；
- 速度计算的 A、B、C 点和纸带上实际选择一致；
- 无随机误差时，纸带计算加速度与实际运动加速度在数值容差内一致；
- 在相同理想条件下，启用理想化阻力比较时，电磁式的实际加速度小于电火花式；
- 时间游标、小车状态和纸带选中时刻一致。

## 15. 实施顺序与风险约束

实施计划应依次覆盖：

1. 备份边界、三文件骨架和共享视觉令牌；
2. A 的器材结构校验、剖面和原理脚本；
3. B 的直接操作状态机和错误恢复；
4. C 的独立纸带物理内核和公式校验；
5. 三文件的学习模式、响应式、可达性和视觉精修；
6. 按各自验收表进行交互、物理、视觉和平板性能验收。

主要风险及约束：

- A 的风险是器材内部结构型号差异；通过教材和实物资料校核、限定表述边界降低风险。
- B 的风险是 Canvas 直接拖动与相机旋转冲突；通过操作步骤中的模式锁定、独立触控热区和手势反馈降低风险。
- C 的风险是将理想化纸带阻力误当作所有实物定量结论；通过参数边界、“理想化模型”标识和不宣称未校准绝对值降低风险。
- 全局风险是为了追求功能完整而重新堆叠面板；实施中严格以每个文件的三个核心功能为范围上限。

## 16. 明确不在本轮实现的内容

- 三文件合并为一个三页签大动画；
- 账号、班级、教师后台、云端数据和长期学习记录；
- 音效、配音、背景音乐和音量控件；
- 三图联动、逐差法、回归拟合、随机误差和不确定度分析；
- 自由拆卸所有三维零件或无限窗口编排；
- 对原始 HTML 的覆盖、删除或整体重写。

## 17. 规格自查结论

- 文档不包含未决定的占位内容。
- 三个文件各有一个主目标和最多一个辅助目标。
- 三维内部结构在 A 中是核心视觉表达，在 B 中仅按操作需要局部调用，C 不重复展开，与已确认拆分一致。
- 顶部标题位置和视觉结构已明确锁定。
- C 中的纸带阻力只是服务辅助目标的理想化可选模型，不冒充实物精确标定。
- 所有验收项都可通过代码、交互、数值或视觉检查明确判定。
