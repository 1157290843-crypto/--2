## 2. 背景与问题诊断

现有页面已同时包含器材结构、打点原理、规范操作、机型比较、纸带计算和错误诊断。三维器材模型、视觉语言和纸带点迹内核具有复用价值，但同一页面中的多个独立教学目标造成信息堆叠、观察重点不唯一和平板侧栏过长。

本设计将原项目拆为三个学习时长约 3–8 分钟的独立动画，使每个文件只有一个主教学目标，并最多保留一个直接服务主目标的辅助目标。

## 3. 已确认的产品结构

### 3.1 输出文件

1. `02A-打点计时器结构与原理-v1.html`
2. `02B-打点计时器规范操作-v1.html`
3. `02C-纸带数据处理-v1.html`

三个文件共用同一套视觉规范、器材几何数据和经校验的打点时序逻辑，但在交付形态中各自内嵌所需代码。学生可单独进入任一文件，无须按 A→B→C 强制学习。

## 6. 02A：结构与工作原理

### 6.1 目标和范围

- 主目标：学生能够根据内部结构解释两种计时器如何形成等时间间隔点迹。
- 辅助目标：理解 `T = 1/f`，并知道 50 Hz 时 `T = 0.02 s`。
- 不进入试验操作训练、纸带定量计算或完整电路推导。

### 6.2 表现和视角

- 高质量三维主场景，结论阶段使用轻量二维原理链；
- 默认为前上方三分之四视角；
- 快捷视角为标准、电磁剖面、电火花剖面和沿纸带方向；
- 外壳渐隐或局部剖切替代零件全屏爆炸展开。

### 6.3 教学脚本

1. 从外观寻找纸带通道、打点位置和电源连接位置。
2. 聚焦电磁式内部结构。
3. 慢放一次“电磁状态变化—振动部件运动—振针打点”。
4. 切换电火花式，观察脉冲放电和点迹形成。
5. 对比两种打点方式，得出共同的时间基准结论。

### 6.4 核心功能

1. 正式三维剖面；
2. 部件点击与原理链逐步高亮；
3. 一次打点过程的通电、暂停和慢放。

可选功能仅保留一张轻量双机型结论卡。若必须继续缩减，先删除完整对照表，不删除三维内部结构。

### 6.5 物理校验要求

- 以教材常见型号和可获得实物资料校核部件名称、相对位置和作用链；
- 不把某一型号的内部结构表述为所有型号的唯一结构；
- 振针振幅、火花尺寸和发光强度可为可视化而适度夸张，但必须标明为视觉辅助；
- 不将电火花式表述为“无接触、完全无阻力”，使用“对纸带的附加阻力较小”。

## 7. 02B：规范实验操作

### 7.1 目标和范围

- 主目标：学生能按正确顺序完成打点计时器实验，并解释关键操作顺序的原因。
- 辅助目标：根据纸带结果识别“先放车后通电”和“停车后未及时断电”。
- 不讲解完整内部原理，不进行速度或加速度定量计算。

### 7.2 表现和视角

- 三维直接操作与二维纸带后果反馈；
- 默认为可同时看见计时器、纸带和小车的侧前方视角；
- 每个步骤开始时自动切换最佳教学视角；
- 穿带步骤使用局部放大或局部透视，不重复 A 的完整剖面学习。

### 7.3 状态机和完成条件

1. **固定计时器**：固定夹到位、计时器方向正确后完成。
2. **穿纸带**：纸带通过正确通道，并完成当前机型的接触关系检查。
3. **接通电源**：已完成穿带检查，且视觉脉冲和点迹达到稳定状态。
4. **释放小车**：只有已通电时才判定为正确，点迹间隔随运动变化。
5. **断电取带**：小车停止后先断电，再取出纸带。

步骤按钮不得跳过完成条件直接把错误状态标记为完成。自动演示和分步引导共用这一状态机。

### 7.4 直接操作

- 点击或拖动固定夹；
- 拖动纸带穿过限位通道；
- 点击电源开关；
- 解锁或释放小车；
- 断电；
- 拖出纸带。

所有可操作对象有触控热区、可操作高亮、手势提示和错误后的可恢复路径。

### 7.5 错误反馈

核心后果对比只保留：

- 先放车后通电：纸带起始段缺失点迹；
- 停车后未及时断电：纸带末端形成重复深点。

没穿限位通道、当前机型的耗材安装错误和计时器未固定作为对应步骤的即时校验，不扩展为额外教学章节。

### 7.6 核心功能

1. 场景内完成五步直接操作；
2. 每步完成条件与错误可恢复状态；
3. 关键顺序错误与纸带后果对比。

机型切换为可选功能。若范围必须继续缩减，先删除 B 中的机型切换，默认以电磁式完成规范操作教学。

## 8. 02C：纸带数据处理

### 8.1 目标和范围

- 主目标：学生能从一条理想化的匀加速纸带中正确选取数据，并用逐差法求加速度。
- 不设辅助目标。
- 不进入某点瞬时速度、机型比较、纸带阻力、随机误差、函数图像、回归拟合或不确定度分析。

### 8.2 表现和视角

- 二维固定物理比例纸带为主场景；
- 纸带、毫米刻度、七个计数点和六段位移保持固定比例；
- 不加入 2.5D 小车、物理时间游标或自动缩放到等宽的纸带；
- 通过逐组高亮 `s_1 ↔ s_4`、`s_2 ↔ s_5`、`s_3 ↔ s_6` 控制信息密度；
- 不展开完整计时器内部结构。

### 8.3 物理内核

打点时刻：

`t_n = n / f`

计数点时间间隔：

`T' = k / f`

其中 `k` 为相邻计数点包含的打点间隔数。

纸带使用不含阻力、随机扰动或测量误差的理想化匀加速运动：

`x_n = v_0 t_n + 0.5 a t_n^2`

默认教学数据使用：

- `f = 50 Hz`；
- `k = 5`；
- `T' = 0.10 s`；
- `v_0 = 0.20 m/s`；
- `a = 2.00 m/s²`。

从 A 到 G 七个连续计数点得到六段理想位移：

`s_1 = 3.0 cm`、`s_2 = 5.0 cm`、`s_3 = 7.0 cm`、`s_4 = 9.0 cm`、`s_5 = 11.0 cm`、`s_6 = 13.0 cm`。

逐差计算：

`a_1 = (s_4 - s_1) / (3T'^2)`

`a_2 = (s_5 - s_2) / (3T'^2)`

`a_3 = (s_6 - s_3) / (3T'^2)`

平均值：

`a = (a_1 + a_2 + a_3) / 3`

合并式：

`a = [(s_4 + s_5 + s_6) - (s_1 + s_2 + s_3)] / (9T'^2)`

在默认理想数据下，`a_1 = a_2 = a_3 = a = 2.00 m/s²`。界面明确说明这是用于学习逐差步骤的理想化纸带，不模拟实验随机误差。

### 8.4 学生操作与系统计算量

学生不调整物理参数。学生直接操作：

- 在纸带上确定 A–G 七个连续计数点；
- 用固定比例刻度读取六段位移；
- 依次选择三组逐差配对；
- 输入或选择三个分组加速度；
- 完成平均值和合并式验证。

系统计算：

- `T'`、六段位移和单位换算；
- `a_1`、`a_2`、`a_3`；
- 三个分组结果的平均值；
- 合并式结果和两种写法的一致性。

### 8.5 教学脚本

1. 确认 50 Hz 时相邻点的时间间隔。
2. 每 5 个间隔选择计数点，得到 `T' = 0.10 s`。
3. 在理想化纸带上确定 A–G 七个连续计数点。
4. 读取 `s_1`–`s_6` 六段位移。
5. 高亮 `s_1 ↔ s_4`，完成第一组逐差。
6. 依次完成 `s_2 ↔ s_5` 和 `s_3 ↔ s_6`。
7. 计算 `a_1`、`a_2`、`a_3` 的平均值。
8. 展开合并式，验证它与分组平均的结果一致。
9. 形成结论：逐差法通过错位配对使用六段数据求加速度。

### 8.6 核心功能

1. 选择七个计数点并读取六段位移；
2. 三组逐差配对的分步高亮与计算；
3. 分组平均与合并式的结果验证。

不增加可选物理参数或误差模块。若界面必须继续缩减，先合并教学提示和结论文字，不删除三组逐差配对。

## 10. 状态与模块边界

每个 HTML 内部至少区分以下责任，即使交付时仍为单文件：

1. **物理或数据状态**：A 保存机型、打点相位和部件状态；B 保存小车、电源、纸带和点迹状态；C 只保存固定理想数据、计数点选择和逐差分组状态。
2. **教学状态**：当前步骤、完成条件、预测、提示和已解锁结论。
3. **场景模块**：几何数据、摄像机、渲染、部件拾取和视角预设。
4. **交互模块**：触控热区、拖动、按钮、键盘可达性和错误恢复。
5. **展示模块**：主场景、观察卡、纸带、公式和底部控制。
6. **教学脚本**：自动演示和分步引导共用的单一步骤定义。

所有展示从同一份物理状态和教学状态派生，不使用相互独立的计时器推动主场景和纸带。

## 11. 异常和边界处理

- 修改必须重新运行的条件时，清空旧点迹并明确提示“新条件将重新运行”；
- 学生尝试未解锁操作时，显示原因和恢复指引，不只禁用按钮；
- 三维部件或标签接近画布边缘时，标签在可视区域内自动避让；
- 有效加速度必须大于零，不合法参数不进入模拟；
- 点迹过密时不改变物理比例欺骗观察，而是提供放大、滚动或局部视窗；
- 视口变化后重新计算画布和触控坐标，不丢失当前教学状态；
- 重置恢复默认参数、标准视角、第一教学步骤和未解锁结论。

## 12. 可达性和可读性

- Canvas 有明确的 `aria-label`；
- 机型、剪切、播放和学习模式控件使用真实按钮状态；
- 不只依赖颜色区分机型、正误或重点，同时使用文字、图形、线型和标签；
- 关键状态变化通过简短文字状态区通知；
- 公式附带可读文字语义和单位；
- 主流键盘操作可访问播放、步骤、机型和视角恢复，不要求键盘用户在 Canvas 上执行精密拖动。

## 13. 性能要求

- 画布像素比设置合理上限，不按超高分屏幕物理像素无限扩大；
- 缓存可复用几何和材质数据；
- 不可见模块停止渲染和高频 DOM 更新；
- 非重点实时数据使用低于主动画的刷新频率；
- C 不加载完整三维内部结构渲染流程；
- 性能不足时先减少装饰光效、非必要标签和隐藏模块刷新，不降低 A 的内部结构质量或 B 的直接操作反馈。

## 14. 验证和验收标准

### 14.1 通用验证

- 三个 HTML 分别在临时 `127.0.0.1` 静态服务器上打开；
- 浏览器控制台无未处理错误；
- 各自的自动演示、分步引导和自由探索共用物理状态，不产生显示不同步；
- 验证 A 和 B 在 0.25×、0.5×、1×、2× 下关键时刻和结果一致；
- 验证 1180×820、1024×768、960×540 下无面板叠压、工具条裁切或主操作不可见；
- 验证标题区位置、品牌、左—中—右三栏布局、配色和字体体系未改变；
- 验证无音频标签、资源请求、控件或预留接口。

### 14.2 A 的验收

- 学生能通过三维剖面找到关键打点链中的部件；
- 一次打点慢放中，高亮部件、运动和点迹时序一致；
- 50 Hz 时打点时刻间隔在数值容差内为 0.02 s；
- 两种机型的文案、电源和打点方式无混淆。

### 14.3 B 的验收

- 正确操作可完成五步流程；
- 未完成前置条件时不会被判定为正确完成；
- 先放车后通电会生成缺失起始点迹的纸带；
- 停车后未断电会在末端形成重复深点；
- 学生可从错误状态恢复，不必刷新页面。

### 14.4 C 的验收

- 默认纸带的七个计数点、六段位移与理想匀加速运动方程一致；
- 50 Hz 且每 5 个打点间隔取一点时，`T' = 0.10 s`；
- `s_1`–`s_6` 的图上标记、列表数值和公式引用一致；
- 三组配对严格为 `s_1 ↔ s_4`、`s_2 ↔ s_5`、`s_3 ↔ s_6`；
- `a_1`、`a_2`、`a_3` 的分母均为 `3T'^2`；
- 默认数据下 `a_1 = a_2 = a_3 = 2.00 m/s²`；
- 分组平均和合并式的结果均为 `2.00 m/s²`；
- 运行期间不使用随机数、纸带阻力、机型切换或测量误差改变纸带数据。

## 15. 实施顺序与风险约束

实施计划应依次覆盖：

1. 备份边界、三文件骨架和共享视觉令牌；
2. A 的器材结构校验、剖面和原理脚本；
3. B 的直接操作状态机和错误恢复；
4. C 的独立纸带物理内核和公式校验；
5. 三文件的学习模式、响应式、可达性和视觉精修；
6. 按各自验收表进行交互、物理、视觉和平板性能验收。

主要风险及约束：

- A 的风险是器材内部结构型号差异；通过教材和实物资料校核、限定表述边界降低风险。
- B 的风险是 Canvas 直接拖动与相机旋转冲突；通过操作步骤中的模式锁定、独立触控热区和手势反馈降低风险。
- C 的风险是六段位移和三组公式同时出现造成信息拥挤；通过每步只高亮一组逐差配对、其余数据弱化降低风险。
- 全局风险是为了追求功能完整而重新堆叠面板；实施中严格以每个文件的三个核心功能为范围上限。

## 16. 明确不在本轮实现的内容

- 三文件合并为一个三页签大动画；
- 账号、班级、教师后台、云端数据和长期学习记录；
- 音效、配音、背景音乐和音量控件；
- 三图联动、瞬时速度计算、机型阻力比较、回归拟合、随机误差和不确定度分析；
- 自由拆卸所有三维零件或无限窗口编排；
- 对原始 HTML 的覆盖、删除或整体重写。
