# 打点计时器三动画：新版引导与标准布局返修设计

## 1. 目标与范围

本轮对已经完成的三个独立 HTML 做增量返修，不重写三维模型、纸带物理内核或操作状态机：

- 修复 02A 步骤内容列没有统一对齐的问题；
- 让三页标题、页眉结构和位置符合项目视觉权威标准；
- 让三页宽屏、窄屏和短横屏布局符合项目视觉权威标准；
- 用项目最新“学生自动演示”规则替换旧的连续点击式引导；
- 保留三页现有主教学目标、物理结论、配色、字体和无声要求。

目标文件：

1. `02A-打点计时器结构与原理-v1.html`
2. `02B-打点计时器规范操作-v1.html`
3. `02C-纸带数据处理-v1.html`

## 2. 标题与统一页眉

三页继续使用唯一可见 `h1`，统一采用“主题｜学习任务”格式：

- A：`打点计时器｜结构怎样形成等时点迹`
- B：`打点计时器｜按正确顺序完成实验`
- C：`纸带逐差法｜用六段位移求加速度`

页眉严格使用项目标准结构：空的 `#headerBackSlot` 位于第一列，品牌和标题位于第二列并左对齐。宽屏、窄屏和短横屏高度分别为 `62px`、`56px`、`46px`；品牌标记分别为 `38px`、`34px`、`30px`；主标题分别为 `20px`、`16px`、`14px`；`11px` 眉题始终显示。

页面内容区不增加第二个重复大标题。

## 3. 学生入口与职责

页面首次打开保持可自由操作，不强制播放。中央舞台上方提供两个同规格入口：

- `实验指南`：打开独立指南，说明学习目标、理想模型、基本原理和操作方法；
- `分步演示`：从确定初态开始连续演示当前动画的完整教学过程。

关闭分步演示后，页面保留当前真实实验状态。入口文字改为 `继续演示`，学生可随时重新进入。自动演示完成后提供：

- `重新播放`：重建当前动画的确定初态并重新演示；
- `现在自己试试`：取消后续自动任务，恢复为可自由操作状态；
- `关闭`：只关闭步骤条，不重置已经形成的实验状态。

实验指南与分步演示职责分离。详细目的、原理和方法放在实验指南；步骤条不复制长说明。

## 4. 分步演示的正常推进逻辑

分步演示采用同一套通用状态：`idle → running/paused → completed → explore`。每一步都包含：

- 动作型短标题；
- 一句“正在发生”；
- 一句“重点看”；
- 默认收起的“为什么？”；
- 对应场景焦点目标；
- 真实完成条件。

演示规则：

1. 点击 `分步演示` 后先取消旧调度任务，再把当前动画恢复到确定初态。
2. 静态说明可以短暂停留；涉及振针、打点、小车和计算状态的步骤必须由真实状态完成信号推进。
3. `暂停` 同时暂停演示调度和当前物理播放；恢复后从原状态继续。
4. `下一步`只能加快静态说明，不能越过尚未满足的真实完成条件。
5. `上一步`用于回看；A 可直接回到相应观察状态，B/C 使用同一物理 reducer 的确定快照重建目标步骤，不伪造第二套结果。
6. 切换页面面板、打开实验指南或浏览器短时失焦不得直接跳过关键步骤。
7. 发生无效状态时停在当前步骤，给出一句可恢复说明和 `重新播放`，不继续错误推进。

## 5. 三页教学步骤

### 5.1 02A：五步结构与原理演示

1. 找到纸带通道、打点位置和电源位置。
2. 打开电磁式剖面，观察线圈如何驱动振片。
3. 慢放一次振针下压，在纸带上形成一个点。
4. 切换电火花式，观察脉冲放电形成点迹。
5. 对比两种机型，形成“结构不同，但相邻点时间间隔相同”的结论。

每一步只突出一个主要观察关系。原左栏整列五步按钮不再承担演示控制；若保留简短进度列表，编号、标题和说明使用固定网格列，所有行严格对齐。

### 5.2 02B：五步规范操作演示

1. 固定并校正计时器方向。
2. 把纸带穿过正确通道并检查耗材接触关系。
3. 接通电源，等待视觉脉冲和点迹稳定。
4. 释放小车，观察已通电条件下形成的连续纸带。
5. 小车停止后先断电，再取出纸带。

自动演示只走正确操作路径。学生自主操作时仍保留两种可恢复错误后果：先放车后通电导致起始段缺点；停车后未及时断电导致末端重复深点。

### 5.3 02C：五步逐差法演示

1. 由 `f = 50 Hz`、`k = 5` 得到 `T′ = 0.10 s`。
2. 确认 A—G 七个计数点并读取 `s₁`—`s₆` 六段位移。
3. 按 `s₁↔s₄`、`s₂↔s₅`、`s₃↔s₆` 依次完成三组逐差；步骤内只高亮当前一组，并显示 `1/3`、`2/3`、`3/3` 子进度。
4. 对 `a₁`、`a₂`、`a₃` 求平均，得到 `2.00 m/s²`。
5. 展开合并式并验证与分组平均一致，形成逐差法结论。

纸带继续使用理想匀加速数据，不加入阻力、随机误差、瞬时速度或回归拟合。

## 6. 步骤条与场景焦点

步骤条位于主舞台内部中央下方，位于既有播放/操作工具栏上方约 `12px`，宽度约为舞台的 `65%–75%`，最大 `720px`。默认只显示：

1. `第 n / 5 步`；
2. 动作型短标题；
3. `正在发生`；
4. `重点看`；
5. 收起的 `为什么？`；
6. 关闭、上一步、暂停/继续、下一步。

步骤条不占用左右栏，不遮挡当前重点模型、纸带读数或舞台工具栏。当前场景目标使用项目关注色描边或柔和外发光，绿色只表示成功、完成或安全状态。

## 7. 标准响应式布局

- 宽屏 `>960px`：保持左参数、中舞台、右观察三栏；推荐列宽为 `clamp(220px,22vw,280px) minmax(0,1fr) clamp(240px,21vw,314px)`。
- `1024px`：仍保持三栏，中央舞台必须比任一侧栏宽。
- 窄屏 `≤960px` 且非短横屏：顺序为标题栏、主舞台、`参数设置 / 观察数据` 标签、单个活动面板。
- 短横屏 `≤960px` 且高度 `≤540px`：标题栏在上；舞台位于左侧并占约 `60%–66%`；右侧顶部为两个标签，下方只显示一个可滚动活动面板。

标签使用原生按钮和标准 `tab/tabpanel` 关系，支持点击、Enter、Space、左右方向键、Home 和 End。切换标签、从窄屏返回宽屏均不得重置模型、参数、时间、图表、答案或观察状态。

## 9. 验收与测试

自动化测试应覆盖：

- 三页新标题和统一页眉结构；
- A/B/C 均为五个主演示阶段，02C 第三阶段包含三个顺序子进度；
- 自动推进不越过未完成的真实状态；
- 暂停、继续、关闭、重新播放和进入自主操作；

- 三页继续离线、自包含、无声音。

浏览器验收通过只监听 `127.0.0.1` 的临时静态服务器进行，检查三个页面在上述尺寸下的标题位置、面板关系、步骤条遮挡、触控区域和关键交互。
