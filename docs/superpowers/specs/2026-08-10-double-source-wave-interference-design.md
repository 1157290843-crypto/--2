## 2. 背景与现状诊断

现有页面已实现双波源干涉场、可点击探测点、`r₁`、`r₂`、`Δr/λ` 实时读数和加强/减弱线。这些是本轮增量改版的主要复用资产。

现有页面的主要问题是：

- 同时展示干涉图样、两张底部图、大量数据、参数、结论和四条易错提示，主教学目标不唯一；
- 页面使用全深色界面，缺少项目标准品牌标题和左—中—右三栏职责；
- 使用了 `19px`、`17px`、`18px`、`15px` 和 `12.5px` 等非标准字号；
- 两列波在波前未到达的区域已参与计算，却又表现为有限波前传播，物理叙事矛盾；
- “`t=d/v` 后全区形成稳定图样”的结论不正确；
- 同时采用距离衰减和“减弱点振幅为零”的理想等振幅结论，模型前提不一致；
- 任意点用宽阈值强制分成加强区或减弱区，忽略了大量非极值点。

## 3. 已确认的教学目标

### 3.1 主目标

学生能根据任意点到两个同相波源的距离，利用 `Δr/λ` 判断该点是加强点、减弱点还是非极值点。

学生完成动画后能够独立执行：

`选点 → 读取 r₁、r₂ → 计算 Δr → 对照 λ → 判断 → 用振动图和干涉线验证`

### 3.2 辅助目标

学生通过所选 P 点的局部振动图理解：波程差决定两波的相位关系，相位关系决定合振幅。

该辅助目标直接支撑主目标，不扩展为完整的波叠加机制课程。

### 3.3 本轮不进入的目标

- 反相波源和任意初相位差；
- `d/λ` 对干涉线数量和疏密的系统探究；
- 有限波列从发射到建立干涉场的传播过程；
- 双缝干涉、光程差和考题训练；
- 账号、评分、班级管理或长期学习记录。

## 4. 物理模型

### 4.1 研究对象与坐标

- 二维均匀、各向同性介质中的两个相干点波源 `S₁`、`S₂`；
- 坐标原点位于两波源中点，`x` 轴沿 `S₁S₂` 从左向右，`y` 轴向上；
- `S₁=(-d/2,0)`，`S₂=(d/2,0)`；
- 视觉坐标必须使用同一等比例尺度映射 `x`、`y`，不得因 Canvas 宽高比改变双曲线和距离几何。

### 4.2 理想条件

- 两波源同相、同频、同振幅、同振动方向；
- 忽略边界反射、吸收和距离衰减；
- 波速 `v` 在当前理想介质中固定；
- 学生改变波长 `λ` 时，系统同步使两波源频率满足 `f=v/λ`，但不把该关系变成另一个学习任务；
- 页面表现的是已建立的稳态干涉场，不显示有限波前。

### 4.3 核心公式

`r₁ = |PS₁|`

`r₂ = |PS₂|`

`Δr = |r₁-r₂|`

`k = 2π/λ`

`ω = 2πf`

`y₁ = A sin(ωt-kr₁)`

`y₂ = A sin(ωt-kr₂)`

`y = y₁+y₂`

`A合 = 2A |cos(πΔr/λ)|`

### 4.4 判定规则

- `Δr=nλ`：加强点，合振幅为 `2A`；
- `Δr=(n+1/2)λ`：减弱点，合振幅为 `0`；
- 其他点：非极值点，合振幅连续取 `0～2A` 之间的值。

引导模式的典型点使用经物理内核生成的精确点，保证分别位于加强线、减弱线和非极值位置。自由探索不用宽阈值将大片区域标为加强或减弱。仅当 `q=Δr/λ` 到最近整数或半整数的差不超过 `0.02` 时，界面可为触控辅助显示“接近加强线”或“接近减弱线”；该命中容差不改变理论判据，界面始终保留实际 `Δr/λ` 和合振幅数值。

### 4.5 参数与边界

- `d`：`1.5～5.0 m`，步长 `0.1 m`，默认 `3.0 m`；
- `λ`：`0.5～2.0 m`，步长 `0.1 m`，默认 `1.0 m`；
- `A`：归一化为 `1`，不向学生开放；
- `v`：系统固定为 `1.0 m/s`，仅用于同步计算时相；
- `r₁`、`r₂`、`Δr`、`Δr/λ`、相位差和合振幅均为系统计算量，不可直接编辑。

极端参数下允许可见加强线或减弱线数量减少，但不改变理论判据；页面不将“线少”误报为模型错误。

## 5. 表现形式与观察策略

### 5.1 主场景

- 使用二维固定俯视图；
- 不提供旋转，不使用 2.5D 水面或 3D 场景；
- 俯视图同时是标准视角和考试建模视角，无需另设视角转换；
- 默认显示实时干涉场、两波源和当前 P 点；
- 选中 P 点后，降低干涉场的对比度，主要突出 `r₁`、`r₂` 两条波程和标签；
- 加强线和减弱线默认不全部显示；当当前 P 点为典型加强点或减弱点时，在预测与判定后只显示经过该点的对应理论线；非极值点不伪造对应干涉线。“显示全部理论线”是可选拓展，不进入核心原型。

### 5.2 主观察链

`看两条波程 → 算波程差 → 对照波长 → 判断 → 验证`

每个教学步骤只设一个主观察关系：

1. P 点的空间位置；
2. P 点到 `S₁`、`S₂` 的两条波程；
3. `r₁`、`r₂` 与 `Δr`；
4. `Δr/λ` 与理论判据；
5. 两波相位关系与合振幅；
6. 同类点形成的干涉线。

## 6. P 点振动图

### 6.1 用途

该图只服务于辅助目标：说明波程差通过相位关系决定合振幅。它不扩展为时间图像综合探究。

### 6.2 曲线与坐标

- 横轴：从 `0` 到 `2T` 的两个振动周期；
- 纵轴：固定为 `-2A～2A`，不随 P 点自动缩放；
- 青色细线：`y₁(t)`；
- 橙色细线：`y₂(t)`；
- 紫色粗线：`y(t)=y₁+y₂`；
- 曲线必须同时使用直接标注、线宽和图例，不只靠颜色区分；
- 图中显示当前相位差和 `A合/2A` 的无量纲比值。

### 6.3 出现时机

- 分步引导：学生完成 `Δr/λ` 预测后才显示，防止绕过波程差直接看振幅猜答案；
- 自动演示：到达“用振动验证”步骤时出现；
- 自由探索：始终位于右侧观察区，随 P 点点击或拖动实时更新。

## 7. 交互、参数和状态

### 7.1 学生操作

- 点击或拖动主场景中的 P 点；
- 调整 `d` 和 `λ`；
- 在引导模式中选择“加强”、“减弱”或“非极值”预测；
- 控制干涉场动画的播放、暂停和播放倍速；
- 如后续实现可选拓展，可在自由探索中显示或隐藏全部理论干涉线；该开关不进入核心原型。

### 7.2 状态边界

页面使用单一物理状态作为主场景、数值、P 点振动图和判定结论的唯一数据源。状态至少包含：

- `mode`：`demo | guide | explore`；
- `step`：当前教学步骤；
- `d`、`lambda`、`time`、`playing`、`speed`；
- `probe`：P 点物理坐标；
- `prediction`：学生原始预测；
- `resultRevealed`：判定和振动图是否已解锁；
- `showLoci`：理论干涉线显示状态。

### 7.3 参数变化

改变 `d` 或 `λ` 时：

- 保留 P 点在主场景的物理坐标，越界时夹取到可见区域；
- 清除旧预测、已解锁结论和当前干涉线高亮；
- 重算 `r₁`、`r₂`、`Δr/λ`、相位差和合振幅；
- 自由探索中可立即更新，引导模式中提示学生重新预测；
- 不将参数变化表述为“从当前时刻继续传播”，因为页面表现的是新条件下的稳态场。

## 8. 学习模式与教学脚本

### 8.1 学习入口

顶部提供：

- “学习目的与模型”；
- “自动演示”；
- “分步引导”；
- “自由探索”。

三种模式共用同一物理内核和同一教学步骤定义，切换模式不重置 `d`、`λ`、P 点或物理时间。

### 8.2 分步引导

1. **提出问题**：指定一个 P 点，请学生预测它是加强点、减弱点还是非极值点。
2. **观察波程**：高亮 `PS₁`、`PS₂`，显示 `r₁`、`r₂` 与单位。
3. **计算波程差**：引导得到 `Δr=|r₁-r₂|`。
4. **对照波长**：计算 `Δr/λ`，请学生完成最终判定。
5. **验证振动**：自动暂停教学流程，显示 P 点振动图、相位关系和合振幅。
6. **验证曲线**：显示经过 P 点的对应理论线，说明具有相同波程差的点组成同类干涉线。
7. **换点再试**：使用第二个典型点完成简化验证，然后进入自由探索。

每步提供任务、操作位置、操作方法、观察焦点和完成条件。提示和“帮我完成”使用同一组典型点和正确物理状态。

### 8.3 自动演示

自动演示使用同一步骤脚本，以预置点演示完整链路。到达振动图验证时自动暂停，但不设置没有物理意义的慢放、波前相遇或“全区图样形成”事件。学生可随时暂停、前后切换教学步骤或接管当前状态。

### 8.4 自由探索

- 可任意拖动 P 点；
- 可调整 `d`、`λ`；
- 右侧同步显示实际波程差、无量纲比值、合振幅和 P 点振动图；
- 保留“继续引导”入口；
- 不将自由探索扩展成参数关系结论教学。

## 11. 功能范围与精简

### 11.1 三个核心功能

1. 点击或拖动 P 点，突出 `r₁`、`r₂`；
2. 通过 `Δr → Δr/λ → 判定` 完成预测和验证；
3. 用单张 P 点振动图和对应干涉线解释判定。

### 11.2 必须实现

- 一致的等振幅物理内核；
- 单一物理状态驱动主场景、数值、图像和结论；
- P 点点击与拖动；
- 预测—计算—验证教学链；
- P 点振动图；
- 标准品牌、三栏、窄屏标签和短横屏布局；
- 自动演示、分步引导和自由探索共用同一步骤脚本；
- 无声引导和 `prefers-reduced-motion` 支持。

### 11.3 可选实现

- 自由探索中显示全部理论加强/减弱线的开关；
- 一道默认折叠、可跳过的“验证一下”判断题。

可选项只在核心原型已通过物理、布局和交互验证后考虑，不得延迟主要交付。

### 11.4 本次不做

- 振幅 `A` 滑块；
- 现有的空间截面图和波程差条带；
- `±0.1 s` 时间单步；
- 波前圆环、“两波相遇”和“全区干涉图样形成”事件；
- 四条常驻易错提示；
- 2.5D、3D、自由视角、材质光效或声音。

### 11.5 最应该删除的功能

如果范围必须继续收缩，先删除“显示全部干涉线”开关，不删除 P 点振动图、波程差判定链或主场景的核心清晰度。

## 12. 可访问性与异常处理

- 滑块使用程序化标签，支持键盘操作并同步显示单位；
- 预测、模式、面板标签和播放控制均使用原生按钮；

- `prefers-reduced-motion` 启用时默认暂停干涉场动画，但保留点击、拖动、计算和图像更新；
- 完整结论在预测或验证前不无条件展示。

## 13. 性能和核心视觉品质

### 13.2 可克制或删除的装饰

### 13.3 性能策略

- 干涉场使用离屏 Canvas 和适配性内部分辨率；
- 主 Canvas 按设备像素比同步 backing store，但可为普通平板设置经验性 DPR 上限；
- 静态干涉线、坐标和背景与时变位移场分层缓存；
- P 点振动图只在 P 点、`d`、`λ` 或尺寸变化时重算曲线，物理播放仅移动时间指示；
- 页面隐藏时暂停动画刷新；
- 优先减少装饰层和非必要重画，不降低核心轨迹、曲线或文字清晰度。

## 14. 验收和测试策略

### 14.1 物理校验

- P 点位于中垂线时 `r₁=r₂`、`Δr=0`、`A合=2A`；
- 左右镜像点的 `Δr` 和合振幅相同；
- 典型加强点满足 `Δr/λ=n`；
- 典型减弱点满足 `Δr/λ=n+1/2`；
- 非极值点的 `A合` 在 `0～2A` 之间连续变化；
- 改变播放倍速不改变 `Δr/λ`、干涉线位置和合振幅；
- 不同 Canvas 宽高比下的波源间距、P 点距离和双曲线形状不失真。

### 14.2 交互校验

- 点击与拖动 P 点均可更新数据和振动图；
- 预测在结果显示后仍保留并可对照；
- 改变参数清除旧结论但不意外重置其他状态；
- 自动演示可暂停、前后移步、接管操作并转入自由探索；
- 窄屏面板标签切换不重置学习状态；
- 无声情况下学生能看懂任务、操作入口、当前焦点和结论。

### 14.3 视觉与布局校验

- 主要验证 1180×820、1024×768 和 960×540；
- 标题品牌、六级字号、颜色 Token、三栏职责和窄屏标签符合视觉标准；
- 页面不出现横向滚动，左右面板或活动面板内部独立纵向滚动；
- 主舞台是宽屏三栏中的最大区域；
- 可见文字不低于 `11px`，不使用整体 `transform:scale()`；
- 主要触控按钮和可拖动 P 点具有适合平板的命中区和明确反馈。

### 14.4 原型通过条件

低成本原型必须同时满足：

1. 中垂线、典型加强点、典型减弱点和非极值点的物理校验通过；
2. P 点拖动、预测、判定、振动图和干涉线联动成立；
3. 1024×768 和 960×540 没有核心控件裁切、文字过小或舞台被挤压；
4. 页面不再包含旧波前事件、距离衰减和宽阈值误分类；
5. 原始 HTML 未被覆盖或删除。

## 15. 实施边界

实施阶段应先建立物理函数和可测试状态，再接入绘图和教学脚本。复用现有代码时：

- 可复用 Canvas 尺寸同步、离屏像素场、点击坐标映射和 `r₁/r₂/Δr` 计算思路；
- 必须替换距离衰减、波前事件、宽阈值判定和非标准页面外壳；
- 不得为了追求“原型快速”而降低已确认的主舞台清晰度、几何正确性、触控反馈或响应式品质；
- 如开发量超出原型预算，优先延后全部干涉线开关和可选检测题，不删除三个核心功能。
