## 3. 已确认的主目标与入口

### 3.1 02A：结构与工作原理

- 主目标：学生能根据内部结构解释电磁式和电火花式计时器如何形成等时间间隔点迹。
- 辅助目标：知道 `T=1/f`，50 Hz 时相邻打点间隔为 `0.02 s`。
- 顶部入口：
  1. `A 电磁式原理`
  2. `B 电火花式原理`
  3. `实验指南`

A、B 是两个直接服务同一主目标的结构情境，不扩展为规范操作或纸带计算。

### 3.2 02B：规范实验操作

- 主目标：学生能按正确顺序完成实验，并解释为什么要先通电后放车、停车后先断电再取带。
- 顶部入口：
  1. `正确操作`
  2. `实验指南`

不设独立“错误后果”入口。现有两种错误后果仅保留在自由操作反馈和指南的“易错点”中，不与正确操作主线争夺入口。

### 3.3 02C：纸带逐差法

- 主目标：学生能从六段理想位移中完成三组逐差并求得加速度。
- 顶部入口：
  1. `分组逐差`
  2. `实验指南`

平均值和合并式是同一逐差流程的结论步骤，不拆成第二个情境入口。继续使用无阻力、无随机误差的理想纸带。

## 4. 页面布局与入口条

### 4.1 宽屏

- 保留左参数、中舞台、右观察三栏骨架。
- 中栏内部先显示入口条，再显示实验舞台；入口条不覆盖画布。
- 入口条与舞台左右边缘严格对齐。
- 02A 三个按钮等宽；02B、02C 两个按钮等宽。
- 入口按钮使用统一蓝白语义、圆角、边框和至少 `44px` 触控高度。
- 当前情境使用蓝底白字；实验指南按钮保持普通状态，打开时通过 `aria-expanded` 表达状态。

### 4.2 窄屏与短横屏

- 窄屏顺序：标题、入口条、舞台、参数/观察标签、单个活动面板。
- 短横屏：左侧是入口条加舞台，右侧是参数/观察标签和单活动面板。
- 短横屏入口条约 `40–44px` 高，舞台使用左列余下空间。
- 分步卡始终属于舞台，不固定塞进右侧面板。
- 面板切换、转屏和窗口缩放不重置物理状态或教学步骤。

## 5. 学生主导的分步演示

### 5.1 通用状态

每个情境共用以下教学状态：

`idle → running → acting → ready → completed → explore`

- `running`：学生阅读当前步骤。
- `acting`：系统正在执行“替我操作”。
- `ready`：当前步骤的真实完成条件已经满足，允许学生点击下一步。
- `completed`：最后结论已呈现。
- `explore`：回到情境初态，交给学生自由操作。

关闭分步卡只隐藏卡片，保留当前物理状态。重新打开同一情境时恢复当前步骤；关闭后重新选择情境则从默认位置和该情境初态开始。

### 5.2 推进规则

- 不因文字停留时间或定时器自动跳到下一步。
- 观察步骤进入后即可由学生点击下一步。
- 需要系统设置参数、切换剖面、执行打点、穿带、通电、放车、断电或计算时，才显示 `替我操作`。
- 操作未完成时禁用下一步；执行中显示 `正在操作…`；真实状态满足后显示 `操作完成` 并解锁下一步。
- 物理动作必须使用现有物理内核和 reducer；不得建立第二套伪动画。
- `上一步`重建对应的确定状态快照，不直接篡改显示结果。
- 学生主动点击下一步后才进入结论，系统不越过阅读时间。

### 5.3 02A 步骤

电磁式和电火花式各使用五步，结构一致、内容不同：

1. 认识纸带通道、打点位置和电源位置，只观察。
2. 查看对应机型内部剖面，只观察。
3. 聚焦驱动链或放电链，需要 `替我操作` 切换到规定结构状态。
4. 执行一次真实振针下压或脉冲放电，需要 `替我操作`，完成后立即暂停观察点迹。
5. 查看“结构不同、相邻点时间间隔相同”的比较结论，只观察。

每个情境只突出一个机型，结论步骤才显示轻量双机型对照。

### 5.4 02B 步骤

正确操作使用五步：

1. 固定并校正计时器方向。
2. 把纸带穿过正确通道并检查接触关系。
3. 先接通电源，等待视觉脉冲和点迹稳定。
4. 后释放小车，观察连续点迹。
5. 小车停止后先断电，再取出纸带并查看结论。

五步均使用现有操作 reducer 的真实状态作为完成条件。学生也可以自己操作；`替我操作`只是在当前步骤调用同一正确动作。错误状态不自动推进，并提供恢复说明。

### 5.5 02C 步骤

分组逐差使用五步：

1. 由 `f=50 Hz`、`k=5` 确认 `T′=0.10 s`，只观察。
2. 确认 A—G 七个计数点和 `s₁–s₆` 六段位移，只观察。
3. 依次完成 `s₁↔s₄`、`s₂↔s₅`、`s₃↔s₆`，显示 `1/3–3/3` 子进度；学生可选择，`替我操作`只完成当前一组。
4. 对 `a₁、a₂、a₃` 求平均；学生可填写，`替我操作`只完成当前计算。
5. 展开合并式验证结果仍为 `2.00 m/s²`，形成逐差法结论。

## 6. 分步卡位置、拖动与层级

### 6.1 默认位置

- 默认位于舞台中央偏下，避让物理重点和播放工具条。
- 宽屏宽度不超过舞台约 `72%` 或 `720px`，距舞台底部约 `76px`。
- 窄屏左右保留约 `12px`，距舞台底部约 `74px`。
- 默认卡为舞台内绝对定位，`z-index:12`。

### 6.2 拖动规则

- 整个卡片标题栏可拖动：拖动图标、步骤编号、标题和空白区都有效。
- 关闭按钮、“为什么？”、正文和底部操作按钮不触发拖动。
- 使用 Pointer Events，兼容鼠标和触屏，非主鼠标键不触发。
- 第一次拖动后改为相对视口固定定位，`z-index:72`。
- 同一次演示内切换步骤、展开“为什么？”和执行操作时保留拖动位置。
- 关闭后重新选择情境恢复默认位置。
- 始终保留 `12px` 视口安全边距；转屏、缩放和内容高度变化后重新夹紧。

### 6.3 层级

| 层级 | 组件 |
| ---: | --- |
| 4 | 舞台 HUD、图例 |
| 5 | Toast |
| 6 | 舞台播放工具条 |
| 10 | 面板内部粘性进度 |
| 12 | 默认分步卡 |
| 40 | 统一标题栏 |
| 68 | 紫色重点框 |
| 72 | 已拖动分步卡 |
| 80 | 实验指南模态弹层 |

不得通过随意增加更大的 `z-index` 解决遮挡；新增定位、`transform`、`filter` 或 `contain` 时必须检查 stacking context。

## 7. 紫色重点观察框

- 每一步只使用一只联合框包围本步相关目标，不给多个控件分别画框。
- 普通控件向外扩约 `32px`；大面积舞台或结论卡向外扩约 `10px`。
- 边框 `5px #9A83FF`，四层自然递减紫色光晕。
- 呼吸周期 `2.8s`，持续显示，不短时闪烁。
- 不显示“重点观察”文字标签；步骤卡正文保留“重点看：”。
- `.scenario-focus-layer` 使用 `pointer-events:none`，`z-index:68`。
- 系统减少动态效果时取消呼吸动画，但保留静态边框。

## 8. 实验指南弹层

- 点击入口打开覆盖全页面的居中模态弹层，最大宽度约 `760px`，内容区内部滚动。
- 顶部平铺三个一级标签：`实验指南 / 常考点 / 易错点`。
- 三块内容分别放在稳定模板接口中：
  - `template#experimentGuideContent`
  - `template#examPointsContent`
  - `template#commonMistakesContent`
- 三页复用同一弹层控制逻辑，只替换模板内容。
- 支持关闭按钮、`Escape`、点击遮罩空白关闭。
- 打开时暂停物理播放；关闭后恢复打开前的播放状态。
- 左右方向键切换标签，关闭后焦点归还实验指南入口。
- 模态层为 `z-index:80`，始终高于重点框和拖动卡。

## 9. 左右面板职责与功能精简

- 左栏只保留条件、机型/实验状态、少量必要参数和重置入口。
- 右栏显示当前观察任务、关键状态、数据、公式和逐步解锁的结论。
- 不在左栏继续放一套与分步卡重复的完整步骤说明。
- 分步卡是唯一的教学步骤控制器；左右栏不再提供第二套“下一步”。
- B 的错误后果不设入口；C 的合并式不设入口；这是本轮主动删除的最低价值重复功能。

## 10. “现在自己试试”与自由操作

- 最后一步完成后显示 `现在自己试试`。
- 点击后取消所有自动任务，把所选情境恢复到确定初态，关闭步骤卡并启用手动控制。
- 02A 恢复所选机型的标准视角和默认剖面状态。
- 02B 恢复正确操作的实验初态；自由操作中仍可触发现有两种可恢复错误反馈。
- 02C 恢复空白计算工作台和同一条理想纸带。
- 自由操作中保留再次选择情境和重新进入实验指南的入口。

## 11. 保留与不做

### 必须保留

- 三页标准标题、品牌结构、配色、六级字号和响应式三栏骨架。

- 不把详细指南文字塞进分步卡。

## 13. 成功标准

学生进入任一页面后能立即看见与该主目标对应的情境入口；选择情境后由自己控制阅读节奏，只在真实操作步骤调用“替我操作”，并通过持续的单一紫色重点框知道该看哪里。分步卡可以主动避让信息，实验指南内容分类清楚，完成后可从确定初态自由验证。整个过程不改变既有物理正确性和核心视觉品质。
